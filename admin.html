📊 ربط المتجر بـ Google Sheets مباشرة

كاع الطلبات والمعلومات (Leads) كيدوزو تلقائياً لشيت ديالك فـ Google Sheets لحظة بلحظة

⏳ غير مربوط

📝 خطوات الربط فـ 30 ثانية (Google Apps Script)

  1. افتح Google Sheet جديد وسمي الهيدرز فـ السطر الأول: name | phone | product
  2. من القائمة الفوقانية اختر: Extensions ➔ Apps Script
  3. امسح الكود القديم وحط هاد الكود المصاوب (اضغط زر نسخ الكود الفوق):
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    
    var name = data.name || data.customer_name || "—";
    var phone = data.phone || data.customer_phone || "—";
    var product = data.product || (data.items ? data.items.map(function(i){return i.name + " (x" + i.qty + ")";}).join(", ") : "—");
    
    sheet.appendRow([name, "'" + phone, product]);
    
    return ContentService.createTextOutput(JSON.stringify({ status: "success" })).setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({ status: "error", message: err.toString() })).setMimeType(ContentService.MimeType.JSON);
  }
}
  1. اضغط على Deploy ➔ New Deployment
  2. اختر Web App وفي خيار Who has access اختر Anyone
  3. انسخ الرابط الناتج عن الـ Deployment وحطو فـ الخانة الفوقانية واضغط حفظ الرابط! 🎉
